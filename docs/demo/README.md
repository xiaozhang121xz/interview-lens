# 脱敏演示：星河咖啡门店补货访谈

本目录展示 TalkAgent 从访谈记录生成结构化结果的完整过程。

> 所有公司、人物、邮箱、业务数字和访谈内容均为虚构，仅用于功能演示，不对应任何真实主体。

## 阅读顺序

1. [原始访谈与证据](01-interview-evidence.md)
2. [访谈纪要](02-summary.md)
3. [PRD 初稿](03-prd.md)
4. [用户画像与旅程图](04-persona-journey.md)

## 演示目标

这个案例重点展示：

- 每一项事实、痛点和需求如何引用 `[R#]` 证据；
- 没有访谈依据的信息如何标记为 `[待确认]`；
- PRD 如何区分事实、推断、非目标和验收标准；
- 画像如何避免虚构年龄、性别和收入等人口属性；
- 旅程图如何从真实行为链路中提取机会点。

这些文件是人工整理的确定性示例，用于说明系统预期输出标准。真实输出会受到所选模型、提示词、访谈质量和上下文长度影响。
